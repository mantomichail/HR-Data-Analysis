# HR Data Analysis with SQL

Analysis of employee data using SQL (SQLite).

## Database
3 tables: departments, employees, performance
10 employees across 4 departments

## Queries
- Filtering with WHERE and ORDER BY
- Aggregation with GROUP BY and AVG
- JOIN across multiple tables
- Filtering groups with HAVING
- 3-table JOIN analysis

## Tools
- SQL (SQLite)
- SQLiteOnline.com
